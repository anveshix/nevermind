Checking setup…
  1. Copy .env.example to .env in the project folder.
  2. Set AI_API_KEY and AI_MODEL for your OpenAI-compatible provider.
  3. Run python3 run.py, then open http://localhost:8317/jenni.html.

Chat text and recent turns are sent to the configured AI provider and are not stored by Jenni's server. Local drafts, tasks, and notes are not attached automatically.

Browser speech recognition may use your browser's speech service. Hands-free mode gates on the phrase “Hey Jenni” but is not an on-device wake-word model. If browser recognition is unavailable, recorded audio is sent to the configured transcription provider.

No Google Drive, email, or remote-send integration is configured. Saving a response creates a local draft only. The browser PIN is a convenience, not account security.

Do not expose this server publicly without authentication and HTTPS. See README.md for setup and privacy details.
